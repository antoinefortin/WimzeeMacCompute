# WimzeeMacCompute

## What you need 
- Xcode Command Line Tools : `xcode-select --install`
- Homebrew : cmake + ninja → `brew install cmake ninja`
- vcpkg cloned somewhere + `export VCPKG_ROOT="$HOME/dev/vcpkg"` dans `~/.zshrc`

## Build
OPen in VS Code (extensions CMake Tools + C/C++), and press F5.
